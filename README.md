# Supplementary Materials

This repository contains supplementary materials for the paper:

**The impact of Artificial Intelligence Innovation and Development Pilot Zones on firms’ AI narrative: Evidence from a quasi-natural experiment**

The materials support the construction of the AI narrative measure from Chinese corporate annual reports.

## Files

- `AI_keyword_dictionary.csv`: The complete AI keyword dictionary, including Chinese terms, English translations, and category labels.
- `stopwords_zh.txt`: The stop-word list used in text preprocessing.
- `requirements.txt`: Package version information.

The dictionary and stop-word list are encoded in UTF-8. English translations are provided for reference; Chinese terms are used for keyword matching.
